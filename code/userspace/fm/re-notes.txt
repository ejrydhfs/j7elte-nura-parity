## 2. Call-site census (capstone, thumbv2; 54 sites -> helpers)

Generator: /tmp/fmx/calls.py (targets SND c46d0, ENQ c471c, W1B c4784,
W2B c479c, W4B c47b8, READ c47e0, SETMASK c485c) over all 132 *fm* symbols;
full per-site context in /tmp/fmx/calls_out.txt (917 lines).
Counts: W1B ~24, W2B ~12, READ ~15, SETMASK 3, SND 2 (vsc_cmpl + read-fallback),
W4B 2 (sub_2264 x2 paths). No other bl NZ into these helpers from fm code.
Quote style used in fc15-table.md: `movs/mov r0,#sub; movs/mov r1,#d; movs/mov r2,#flags; bl #0xc47xx`.

Per-site register triples (r0=sub, r1=data, r2=flags; [cb+off] = cached word):
- init_delay: W1B(02, 02|03, 00); R(4D, r1=0, 01); W2B(05, [a6]|1c|1d, 88)
- enable: W1B(00, r7=01|03 region, 00)
- disable: W1B(4D, a5&7f, 00); W2B(05, 0002, 08); W1B(00, 00, 88)
- sub_2264: W1B(01, class, 00|88); W4B(FB, lo, hi, 08)
- sub_21fc: W2B(0A, u16, 00); post 2319; W1B(09, 00, 08)
- tune: range-check only, then b.w sub_21fc (same bytes as above)
- scan: W1B(14, .., 00) park; W2B(16, 03e0|0400, 00); W2B(18, r8, 00);
  W2B(05, [a6]|02, 00); W1B(FC, sb&1, 00); W1B(FC, 03, 00) if seeking;
  R(FC, 00, 01); W1B(08, .., 00) if ce>1f; W1B(DE, [cf], 00) if d0;
  W1B(FE, sl, 08); W1B(07, [cd]|b4nib, 08)
- abort: W1B(09, 01, 08|88 by ac&4)
- read_rds: R(80, 00|?, F0); then set_mask(88, 00, 3a98) on NULL leg
- set_audio_path: W1B(4D, a5', 08); W2B(05, ±20 ±10, 88)
- update_aud_data: R(0F, 00, 01); R(DF, 00, 01); then set_mask tail (shared bytes c2c06..)
- q_evt/check_rds: W1B(00, 03, 00); R(0A, 00, 02)
